# Лабораторная работа №5

## Сборка и запуск

Настроить проект:

```powershell
cmake --preset mingw-debug
```

Собрать нужный листинг, например `list1`:

```powershell
cmake --build --preset mingw-debug --target list1
```

Запустить программу:

```powershell
.\out\build\mingw-debug\list1.exe
```

Для запуска других заданий замените `list1` на `list2`, `list3` или `list4`
